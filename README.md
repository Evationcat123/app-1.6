# WebBoard

Native Android IME keyboard with an embedded browser.

## Features
- QWERTZ German layout
- Numbers and special characters via ?123
- Integrated browser inside the keyboard window
- Web page HTML inputs are editable using WebBoard itself; tapping Google search, YouTube search, etc. routes key input to the focused web element without opening a second keyboard
- Quick links button with YouTube, Google and Asura Scans
- Dark modern rounded-key design
- Browser navigation and address/search field
- GitHub Actions cloud build included

## Cloud build
Upload the contents of this archive to the repository root, then use Actions > Build WebBoard APK > Run workflow.
